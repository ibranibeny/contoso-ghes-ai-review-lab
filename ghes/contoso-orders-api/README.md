# contoso-orders-api

Order service for the Contoso storefront (lab sample). Flask + SQLite, money in integer minor units (ADR-0007).

Every pull request is reviewed by the **AI review** workflow: Microsoft Foundry through the Contoso AI gateway,
grounded with Contoso standards over MCP. The `ai-review/foundry` status is required on `main`; a human approves the merge.
